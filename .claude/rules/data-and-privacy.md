# Data & privacy

METABRIC is **access-controlled**: EGA `EGAS00000000083`, Synapse `syn1688369`. Holding a copy
does not grant the right to redistribute it.

- Never `git add` anything under `data/`, and never commit a derived file that still holds
  patient-level rows — `.csv`, `.parquet`, `.nc`, or a notebook with outputs.
- Never print, log or paste patient-level rows. Aggregates (n, %, medians over >= 10 patients)
  are fine; individual records are not, including inside a traceback or an error message.
- Tests use `tests/fixtures/synthetic_metabric.csv`, generated by
  `tests/fixtures/make_synthetic_metabric.py` and containing no real patient. Tests must never
  read `data/` — a test that needs real data is misdesigned.
- `data/raw/` is immutable — derived tables go to `data/interim/` or `data/processed/`.
- Record provenance in `data/raw/CHECKSUMS.sha256`, the one committed file under `data/`, so
  the snapshot behind any result stays identifiable.

Loading goes through `src/brca/data/load.py`, which validates against `src/brca/data/schema.py`
and fails loudly on a missing or mistyped column. Never bypass it with a bare `pd.read_csv`.

Variable definitions and coding: `docs/metabric-data-dictionary.md`.
